# CSE Final-Year Major Project Report

## Abstract
In higher education, effective time management and schedule optimization play a critical role in academic success. This project presents an enterprise-grade **AI Study Planner** designed to automate timetable allocation for Computer Science engineering students.

## 1. System Design & Technical Implementation
- **Frontend Architecture**: Built using React 18, Vite, and Lucide React icons with a custom glassmorphism design system.
- **Backend Service Layer**: Developed using Spring Boot 3.2, Spring Security 6, JWT stateless authentication, and Spring Data JPA.
- **AI Algorithm Engine**: Implements a hybrid approach combining Dynamic Programming slot allocation with a heuristic Task Urgency Index model.

## 2. Conclusion & Future Enhancements
The AI Study Planner demonstrates superior schedule optimization efficiency over conventional manual calendar systems. Future enhancements include calendar synchronization (Google Calendar / Outlook API) and real-time biometric focus tracking.
