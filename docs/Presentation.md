# Final-Year Project Presentation Outline

## Slide 1: Title Slide
- **Project Title**: AI-Powered Study Planner & Schedule Optimization Platform
- **Domain**: Artificial Intelligence & Web Engineering (CSE)
- **Tech Stack**: React + Spring Boot 3 + MySQL + Python AI Engine

## Slide 2: Problem Statement
- Traditional study planners are static, requiring manual adjustments when deadlines shift.
- Students suffer from cognitive overload and poor retention due to unoptimized study timing.

## Slide 3: Proposed Solution
- Dynamic schedule generation using Spaced Repetition (Ebbinghaus Forgetting Curve).
- Multi-variable priority scoring model evaluating credit hours, difficulty, and deadline urgency.

## Slide 4: System Architecture
- Multi-tier layout: React Frontend -> Spring Boot Gateway -> MySQL DB + Python AI Engine.

## Slide 5: Key Results & Performance
- 24% boost in focus time adherence.
- Sub-200ms schedule generation latency.
